## Idea 1：DMARC Report Monitor（Cloudflare 原生）

- **Pitch**：把 DMARC `rua` 加到 DNS，我们收 XML 报告、解析、每周邮件告诉你"谁在冒用你的域名、哪个发信源 SPF/DKIM 没对齐"，异常即时告警。
- **Buyer**：小 SaaS 创始人、电商店主、管理 5–50 个客户域名的 agency/MSP。触发点：Gmail/Yahoo/Microsoft bulk sender 规则要求 DMARC，邮件进垃圾箱或被拒。
- **技术契合**：Cloudflare Email Routing → Worker 收报告 → D1 存储 → Cron 发 digest。无 LLM 成本，毛利 >90%。
- **Acquisition channel（精确）**：
  1. 免费 SEO 工具页：`DMARC record checker`、`DMARC XML report viewer`（拖入 .xml/.gz 即出可视化）、`SPF lookup/flatten checker` —— 高意图搜索词。
  2. Programmatic SEO：`DMARC setup for {Google Workspace|SendGrid|Mailchimp|Shopify|Postmark|...}` × 50+ 页。
  3. 工具结果页内 CTA："把这个 rua 地址加到 DNS，自动持续监控"。
- **Conversion moment**：他们付费当——免费 14 天监控期内第一份 digest 显示"有未授权发信源 / 某 ESP DKIM 失败"，并且想继续收告警；或 agency 需要添加第 2 个以上域名。
- **Price**：Starter $9/mo（3 域名）· Pro $29/mo（15 域名 + 即时告警）· Agency $79/mo（100 域名 + white-label 报告 PDF）。年付 2 个月免费。
- **漏斗假设**：工具页访客 → 添加 rua 3% → 试用转付费 15%。1 万 UV/月 ≈ 45 新付费/月。
- **CAC**：≈ $0（SEO + 工具页自然流量；仅需域名与时间成本）。
- **Biggest risk**：赛道已有 dmarcian、EasyDMARC、Postmark 免费 weekly digest、Cloudflare 自带 DMARC Management（免费）[待验证]。差异化必须是 **agency 多域名 + 白标报告**，否则会被免费品压价。SEO 冷启动需 2–4 个月。

## Idea 2：License & SBOM Report Action（GitHub Marketplace 分发）

- **Pitch**：一个 GitHub Action，每次 push 生成 SBOM (CycloneDX/SPDX) + 开源 license 合规报告 + 第三方 attribution 文件，一键导出给客户采购/安全问卷用的 PDF。
- **Buyer**：卖给企业客户的 2–30 人软件公司 CTO/创始人。触发点：大客户采购或安全问卷要求 "provide SBOM / OSS license list"，单子卡住；EU Cyber Resilience Act 的义务逐步生效 [待验证具体日期]。
- **技术契合**：Action 本身在用户 runner 里跑（我们零算力成本），报告上传到 Worker → R2，生成分享链接/PDF。
- **Acquisition channel（精确）**：
  1. GitHub Marketplace Actions 列表（搜索 `sbom`、`license check`）—— 开发者在此主动找工具。
  2. 分发循环：公开 repo 免费，生成的 `THIRD_PARTY_NOTICES` 与 README badge 带 "Generated by X" 链接，每个用户成为广告位。
  3. SEO：`how to generate SBOM for {npm|python|go}`、`SBOM for security questionnaire`、`GPL in dependencies check`。
- **Conversion moment**：他们付费当——在 private repo 上运行（Action 检测到私有仓库，需 license key），或需要"给客户看的"品牌化 PDF 报告/公开 trust 链接；最强时刻是采购截止日前一周。
- **Price**：Public repo 免费 · Team $19/mo（5 private repos）· Business $49/mo（无限 repo + PDF + license policy 阻断 PR）。另设 $99 one-time "Audit Pack"（单次完整报告，适合急单）。
- **CAC**：≈ $0（Marketplace 列表 + badge 病毒循环 + SEO）。
- **Biggest risk**：免费开源工具（Syft、`anchore/sbom-action`、GitHub 自带 dependency graph SBOM 导出）已能生成 SBOM [待验证]；我们卖的不是 SBOM 本身，而是"可交给客户的合规交付物 + 策略阻断"。若买家认为 GitHub 原生导出够用，转化率会很低。license 判定错误还有声誉风险。

## 对比与建议

| 维度 | DMARC Monitor | License/SBOM Action |
|---|---|---|
| 紧迫性 | 高（邮件被拒 = 收入损失） | 高但偶发（采购事件触发） |
| 获客渠道确定性 | SEO 工具页，高意图词清晰 | Marketplace + 病毒 badge |
| 构建时间 | ~1 周 MVP | ~1–2 周 MVP |
| 留存 | 高（DNS 设好就不会撤） | 中（事件过后可能取消） |
| 主要竞争 | 免费 digest 类产品 | 免费开源 SBOM 工具 |

**我的排序**：Idea 1 优先。DNS 里的 `rua` 是天然锁定（换供应商需改 DNS），churn 低，LTV 高；Cloudflare 全栈原生，零人工支持可行。

## 追踪指标（上线第 1 天起）
- 输入：工具页 UV/周、免费工具使用次数
- 过程：工具 → 开始监控转化率（目标 ≥3%）、试用 → 付费（目标 ≥15%）
- 输出：MRR、付费客户数、月 churn（目标 <3%）、LTV:CAC（CAC≈0，关注回本周期 <1 月）
